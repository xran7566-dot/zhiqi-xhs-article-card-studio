# 智企小红书文章成卡工坊

独立的“内容拆解 → Article 模板渲染” Skill。

输入文章、文案、字幕、截图或笔记，先拆成封面、金句、正文、要点和结尾，再输出小红书 3:4 图文 PNG。

## 安装

```bash
npx skills add https://github.com/xran7566-dot/zhiqi-xhs-article-card-studio --skill zhiqi-xhs-article-card-studio
```

## 使用

```text
使用智企小红书文章成卡工坊，把这篇文章拆成 6 张小红书图文，使用 Article 的 E 雅刊皮肤。
```

它与 `zhiqi-xhs-content-card-studio` 是两个独立 Skill，不共享资源、不互相调用。

许可与上游来源见 `NOTICE.md`。
